# Contributing to AR Router Inspector

欢迎贡献代码！请阅读以下指南来了解如何参与项目。

## 行为准则

请保持友好、尊重和专业的态度。

## 如何贡献

### 1. Fork 项目

点击 GitHub 页面上的 "Fork" 按钮。

### 2. 克隆仓库

```bash
git clone https://github.com/your-username/ar-inspect.git
cd ar-inspect
```

### 3. 创建分支

```bash
git checkout -b feature/your-feature-name
```

### 4. 开发和测试

- 编写代码
- 确保代码符合项目风格
- 运行测试

### 5. 提交更改

```bash
git add .
git commit -m "feat: 描述你的更改"
```

### 6. 推送到远程仓库

```bash
git push origin feature/your-feature-name
```

### 7. 创建 Pull Request

在 GitHub 上创建 Pull Request。

## 代码风格

- 使用 Python 3.11+ 特性
- 遵循 PEP 8 规范
- 使用类型提示
- 保持代码简洁

## 报告问题

如果发现 bug 或有功能建议，请创建 Issue。

## 联系方式

如有疑问，请通过 Issue 联系我们。
